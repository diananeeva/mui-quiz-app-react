
# Quiz Application

This is a simple quiz application built with React and Material UI (MUI). It allows users to take a quiz, select answers, and check their results at the end.

## Features

- Displays multiple-choice questions with answer options.
- Tracks the user's score as they answer questions.
- Shows a summary of correct and incorrect answers at the end of the quiz.
- Allows the user to restart the quiz.

## Technologies Used

- **React**: JavaScript library for building user interfaces.
- **Material UI (MUI)**: A popular React UI framework for building responsive, visually appealing interfaces.
- **JavaScript**: Programming language used for logic and interactivity.
